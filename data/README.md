# Dataset Instructions

## CIC-IDS2017

1. Download the dataset from the [Canadian Institute for Cybersecurity](https://www.unb.ca/cic/datasets/ids-2017.html).
2. Extract the files into this directory (`data/raw/`).
3. The expected files include daily CSVs such as:
   - `Monday-WorkingHours.pcap_ISCX.csv`
   - `Tuesday-WorkingHours.pcap_ISCX.csv`
   - ...
4. Do **not** commit raw data files to git. This directory is gitignored.

## Alternative Datasets

- **NSL-KDD:** Smaller, classic benchmark. Available at https://www.unb.ca/cic/datasets/nsl.html
- **UNSW-NB15:** Modern attack diversity. Available at https://www.unsw.adfa.edu.au/unsw-canberra-cyber/cybersecurity/research/unsw-nb15-dataset/
